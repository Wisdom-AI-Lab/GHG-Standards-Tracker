# Implementation provenance

The repository was created as a GitHub fork of [jmz5033/GHG-Standards-Tracker](https://github.com/jmz5033/GHG-Standards-Tracker). Its general function—a source-linked tracker of changing GHG standards—was used as a reference.

This replacement working version was written from scratch for Wisdom AI Lab: HTML, CSS, JavaScript, schema, original summaries, tests and operational documentation. It does not reuse the reference project's code, visual assets, compiled dataset, text or live data service. It uses standard browser APIs, system fonts and no external runtime libraries.

The reference project's inherited `data/data.json`, `og.png`, `UPDATE_GUIDE.md` and `VERIFICATION.md` are removed from the new working tree. The earlier `index.html` and README are replaced. Earlier commits remain in Git history. GitHub may continue to display the fork relationship; no history rewrite or repository detachment is attempted.

This document is a provenance statement, not a licence for earlier commits or third-party material. No blanket licence is added to the repository by this change. Source publishers retain rights in their standards, publications and other materials. The new dataset links to authoritative sources and contains short original summaries; it does not reproduce standards documents.

Do not use upstream “Sync fork” merges without reviewing them: the original project and this implementation now have different structures, datasets and runtime behaviour.
